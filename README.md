# PHOTOBOX

A modern digital photo booth built with Next.js, TypeScript, Tailwind CSS, browser camera APIs, and Canvas.

![Support NandaCoba on Saweria](public/saweria-support.png)

Support this project at [saweria.co/nandacoba](https://saweria.co/nandacoba).

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Features

- Camera preview with local browser permissions
- Timed multi-photo capture sessions
- Realtime photo filters
- Customizable paper strip layouts
- Paper colors and paper decorations
- PNG download rendered with Canvas
- Print-friendly result view
- Local-only photo handling
